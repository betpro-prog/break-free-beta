# BREAK FREE – Smoke Less (v0.3 beta)

Free experimental mobile-friendly web app for adults who want to explore brief distraction exercises and track smoking habits.

**Status:** prototype; not a medical treatment, not a verified smoking-cessation method, not an App Store/Google Play app.

## Features
- Optional virtual cigarette simulation (may trigger cravings for some users)
- Breathing pause as an alternative
- Self-reported smoking and savings tracking
- 8 interface languages
- Browser-local storage, no account
- No ads, payments, or subscriptions

**Safety:** If cigarette visuals increase cravings, skip the virtual ritual and use the breathing exercise instead. Consult a healthcare professional for proven quitting support.

## Privacy
User-entered goals and smoking records are stored locally in the browser. They are not sent to a custom backend in this beta. See [privacy.html](privacy.html) and [testing.html](testing.html) for details.

## Deploy FREE with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, set **Source: Deploy from a branch**.
3. Set **Branch: main** and **Folder: /(root)**.
4. Tap **Save**. GitHub may take a few minutes to deploy.
5. Visit https://betpro-prog.github.io/break-free-beta/ when Pages shows a successful deployment.

The app uses only static HTML and JavaScript; `index.html` is the entry point. The source is publicly visible because this repository is public.
